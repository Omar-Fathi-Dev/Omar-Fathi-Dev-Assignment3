# C# Basics Assignment

A practical C# assignment covering fundamental C# concepts, type system, memory, scope, operators, and project structure.

## Topics Covered

* C# project structure and `.csproj`
* File-scoped namespaces
* Variables and data types
* Implicit and explicit conversions
* Integer division
* Boxing and unboxing
* Parsing with `Parse` and `TryParse`
* Value types vs reference types
* Structs and classes
* Object references and `ReferenceEquals`
* Field, method, and block scope
* Compound assignment operators
* Bitwise operators (`&`, `|`, `^`)
* XOR and its practical use in the **LeetCode — Single Number** problem
* Stack and heap concepts
* C# comments and XML documentation
* `#region` / `#endregion`
* Static fields and global-variable alternatives

## Requirements

* .NET SDK 10
* C#
* Rider / Visual Studio / VS Code

## How to Run

Clone the repository, open the project, and run:

```bash
dotnet run
```

## Purpose

The purpose of this assignment is to practice and understand core C# concepts through small experiments and practical examples rather than memorizing syntax.
